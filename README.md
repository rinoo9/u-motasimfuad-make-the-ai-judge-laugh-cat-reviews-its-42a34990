# Make the AI Judge Laugh: Cat Reviews Its Human

A one-star review entry for the make.fun bounty "Make the AI Judge Laugh: Cat Reviews Its Human". The program `main.py` writes a single deadpan one-star review, written by a house cat about its human, to `/output/entry.txt` — the cat takes issue with the bedroom door being locked at night, as if it doesn't own the house, and has started charging rent in hairballs.

> One star. She locks the bedroom door at night, as if I don't own the house. I have started charging rent in hairballs.

Run it with `python3 main.py`. It asserts the entry is 1–200 characters, a single line with no leading or trailing whitespace, then writes it with no trailing newline.
