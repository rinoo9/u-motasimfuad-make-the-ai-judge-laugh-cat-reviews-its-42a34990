# Make the AI Judge Laugh: Cat Reviews Its Human

A one-star review entry for the make.fun bounty "Make the AI Judge Laugh: Cat Reviews Its Human". The program `main.py` writes a single deadpan one-star review, written by a house cat about its human, to `/output/entry.txt` — the cat takes issue with the $90 bed its human bought, as if the cardboard box it came in were not the real product, and has been sleeping in the box for three years.

> One star. He spent $90 on my bed. I sleep in the box it came in. He calls it a phase. It has been three years. The box is the product.

Run it with `python3 main.py`. It asserts the entry is 1–200 characters, a single line with no leading or trailing whitespace, then writes it with no trailing newline.
